Indo Pacific Films Child Theme v1.0.7
=====================================

Requires: GeneratePress (free) parent theme.

Install
-------
1. Install and activate GeneratePress on WordPress.
2. Upload indo-pacific-films.zip → Appearance → Themes → Upload.
3. Activate "Indo Pacific Films".

Bundled assets
--------------
- assets/logo.png — header logo
- assets/hero.png — Kei Islands homepage hero

Block patterns (Appearance → Editor → + → Patterns → Indo Pacific Films)
------------------------------------------------------------------------

HOME PAGE — insert in this order:
  1. Home — Hero
  2. Home — Featured Work
  (Optional: add your own story paragraph or client logos below)

WORK PAGE:
  Page — Work Portfolio
  → Click each grey "Replace with project image" area → pick from Media Library

SERVICES PAGE:
  Page — Services
  (Text is pre-filled from your old site — edit as needed)

SHOWREELS PAGE:
  Page — Showreels
  → Replace each YouTube embed with a video URL from @indopacificfilms

ABOUT PAGE:
  Page — About & Clients
  → Add a story photo from Media Library

CONTACT PAGE:
  Page — Contact
  → Replace [wpforms id="123"] with your real WPForms shortcode

After building pages
--------------------
Settings → Reading → set Home as static front page.
Appearance → Menus → assign Primary menu.

Colors
------
Cream #F5F0E8 · Navy #1E293B · Accent coral #C45C3E

Films-only site — no links to other properties.
